# 明确不做的事（Non-Goals）

| 不做 | 原因 |
|---|---|
| 出售自动化（BUFF/C5/UU/ECO 卖货发货） | 本项目聚焦租赁；出售发货逻辑复杂且非核心收益源。架构预留 ChannelAdapter 扩展位 |
| Steam 出售域自动化（BUFF/C5 发货、市场挂单） | 聚焦租赁闭环 |
| Steam 本地加速/代理内置 | 部署层职责 |

> 2026-08-23 范围修订：Steam 会话（登录/收报价/手机确认）已**纳入目标**——
> 租赁归还与礼物自动接收依赖它。规格见 design/platform-steam-api-notes.md
| 多用户/SaaS 化 | 单管理员自用系统；认证模型保持单用户 JWT |
| 自动买入/求购 | 资金风险高，超出无人值守授权范围 |
| 移动端适配 | 桌面浏览器优先即可 |
| 高频套利型改价（秒级抢单） | 触发平台风控代价大；改价节奏以分钟级为上限 |
| 平台回调/WebSocket 实时推送（首期） | 轮询已满足分钟级业务节奏；列为后续增强（见 architecture.md 演进节） |
| 押金理财/资金再投资 | 押金只是风险保证金，不做金融化 |

## 显式限制（接受）

- UU 登录依赖手机短信验证码：token 失效需人工在面板重新登录
- ECO 无公开租赁行情接口：ECO 侧租金信号只能来自自有订单实现收益 + UU 行情外推
- 平台风控不可控：系统以保守限频+抖动自保，不对抗风控
