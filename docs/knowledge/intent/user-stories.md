# 用户故事清单

> 验收标准详见 spec/functional-spec.md 对应章节。编号规则：US-<页面/域>-NN。

## 仪表盘 US-DASH

- US-DASH-01 我打开面板即看到：总资产、总收入、年化收益率、在租件数、今日租金收入、各渠道健康状态
- US-DASH-02 我能看到近 30 天收益曲线与近 30 天出租单量趋势
- US-DASH-03 任一渠道 token/签名失效时仪表盘出现显著告警条

## 库存状态 US-INV

- US-INV-01 我能查看全部库存：所在渠道、市场名、参考价、成本价、当前状态(在库/已上架/已租出/锁定)、账面收益率
- US-INV-02 我能为任意库存项录入/修改成本价（手工或从平台同步）
- US-INV-03 我能按渠道、品类、状态、关键字筛选排序

## 上架状态 US-LIST

- US-LIST-01 我能分渠道查看租赁货架：当前租金/长租租金/押金/最大天数/最近改价时间/距上次改价的行情变化
- US-LIST-02 我能看到每条货架记录对应的策略与最近一次决策依据摘要
- US-LIST-03 我能手动触发单件商品立即重定价（走完整策略+护栏+dry-run开关）

## 租赁订单 US-ORDER

- US-ORDER-01 我能查看两渠道出租中订单：商品、租期类型(短/长)、已租天数、应收租金、押金、归还倒计时
- US-ORDER-02 我能查询历史订单流水并导出 CSV
- US-ORDER-03 订单完成/买断后自动计入收益统计

## 策略配置 US-STRAT

- US-STRAT-01 我能配置全局默认策略：基准参数、反馈控制器参数、护栏边界
- US-STRAT-02 我能为单个模板(market_hash_name)建立覆盖策略并指定优先级
- US-STRAT-03 我能配置渠道路由：某模板 uu-only / eco-only / both / 主备切换
- US-STRAT-04 新策略首次运行必须 dry-run，我能在面板确认模拟结果后再启用真实执行
- US-STRAT-05 黑名单模板永不参与自动上架/改价

## 渠道账号 US-CHAN

- US-CHAN-01 我能在面板内完成 UU 短信登录（发送验证码→提交→token 校验入库）；
  当平台判定该手机号走短信上行时，面板展示"编辑短信 X 发送至 Y"指引，留空验证码完成登录
- US-CHAN-02 我能配置 ECO partnerId 与 RSA 私钥（保存时校验签名连通性）
- US-CHAN-03 凭证仅显示尾号，不可回显明文

## 审计 US-AUDIT

- US-AUDIT-01 所有写操作（上架/改价/下架/0CD/策略变更/凭证变更）有审计记录：时间、来源(system/user)、动作、前后值
- US-AUDIT-02 我能按时间/渠道/动作过滤审计日志

## 自动化任务 US-AUTO（非页面，后台行为）

- US-AUTO-01 每日定时把符合策略的库存上架到路由指定渠道
- US-AUTO-02 每 N 分钟对在架商品按最新行情+反馈因子重定价（带抖动与频控）
- US-AUTO-03 每日定时为可转租订单开启 0CD（UU）
- US-AUTO-04 Reconciler 周期对账：期望货架 vs 双渠道实际货架差异 → 修复队列
- US-AUTO-05 行情采集器周期拉取 UU 租赁行情 topN 快照；每小时拉取 ECO 全量价格锚点（≥60s 间隔）
