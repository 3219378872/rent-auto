# 产品愿景

## 一句话

让个人 Steam 饰品租赁业务在 UU/ECO 双渠道**长期无人值守地最大化收益**，
并以管理面板提供完全可观测、可干预的运营界面。

## 背景

- 上游 Steamauto（Python）验证了 UU 租赁自动化与 ECO 货架同步的可行性，但：
  - 无管理面板、无收益统计、无跨渠道价格基准、无风控护栏
  - 定价策略固定（均值压价），不能按出租转化反馈调优
- 本项目以纯 Go 重写所需平台对接逻辑（见 ADR-0001），把"能自动跑"升级为"跑得最赚、看得见、可审计"。

## 核心目标（按优先级）

1. **可靠性**：长期无人值守运行；单渠道凭证失效不中断另一渠道运营
2. **收益**：单位库存的租金收益率持续提升，且有数据佐证（回测/对照）
3. **可观测**：任何一笔自动改价都可解释——基于什么行情快照、哪个策略版本、哪个信号
4. **安全**：平台凭证加密存储；所有写操作留审计痕迹；默认 dry-run 起新策略

## 成功标准

- 系统连续运行 ≥7 天无需人工干预（除平台侧强制要求）
- 每件商品的当前租金都能追溯到：价值锚点 V、行情分位数、反馈因子、护栏约束四要素
- 面板展示的总资产/总收入与平台后台手工核对误差 <1%
