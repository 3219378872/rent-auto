# ADR-0010: 实物资产归一与可修正收益投影

日期：2026-09-08
状态：已接受

## 背景

渠道库存是同一实物的多个观测，不是多份资产。仅使用 income_recorded 布尔值也无法
处理平台对已完结订单的金额/日期修正和后续身份补全。

## 决策

- 维持现有渠道库存表，查询时按单账号 CS2 asset_id 形成实物视图，不引入多账号资产模型。
- 最近非 missing 观测优先提供状态/模板；所有渠道均 missing 时不计入持有估值。
  非空成本按人工来源、最后成本修订时刻和稳定行 ID 决定，不重复求和。
- cost_updated_at 记录首次实际成本，cost_modified_at 用于成本冲突裁定。
  人工修改同一 asset_id 的成本同步更新已有镜像；不同实物即便同模板仍独立计数。
- 用 order_income_ledger 保存每笔订单当前已应用的收入投影。锁定原订单后重读数据，
  以旧投影冲销、新投影记账的事务更新 daily_stats，允许重试、并发与终态撤回。
- 全量迁移按已有订单重建收入/单量，保留其他日汇总字段。该步骤修正聚合口径，不能恢复
  缺失的上游原始事实，部署前仍须备份。
- 品类采用当前模板映射，变化后下一轮收益投影迁移到新类别，不承诺交易发生时的历史品类快照。

## 后果

统计不会因双渠道镜像翻倍；订单修订不再重复累计或永久遗漏。历史成本冲突有确定性取值，
但运营仍需核对实际买入成本。真实完结时间缺失时采用稳定的首次终态观测时间，并显式记录口径。
