# ADR-0012：面板读取执行许可与历史决策

日期：2026-09-19。状态：采纳。

## 背景

UX-01/03/08 发现面板看不到有效执行许可、完整定价结果与统计元数据。普通 audit_log
和 price_actions 是不同数据源，模板开关不能代表环境和全局总闸已经开放。

## 决策

新增受认证的只读 `/execution/status`、`/price-actions`，扩展现有列表与统计读模型。
执行许可使用运行时明确装配的环境 dry-run 和 GetEffectiveStrategy 的相同合并规则。
配置未装配或读取失败时报告未知，不默认展示允许真实执行。

历史记录直接读取 price_actions，保留 null、dry_run、success；不拿当前参数反推历史。
API 对错误和敏感 detail 做脱敏，前端以结构化摘要与完整可读的公开字段详情展示。
本轮无需新表/迁移，不补造历史策略版本、行情快照或逐次任务 ID。

全局任务维持现有入口和全部策略/冷却/护栏/审计检查，前端明确范围并读取任务名级状态。
单件/批量目标调度与持久化运行历史留给独立实现，不在浏览器中模拟该能力。

## 影响与验证

React 原生表单/对话框和现有路由库承担交互，无新 UI 框架。列表排序只从固定 SQL 片段选择，
过滤值使用参数绑定，保持 page_size<=200。通过隔离 PostgreSQL API 集成测试验证分页、过滤、
历史模式区分、配置缺失与脱敏；浏览器验证数字草稿、保存防重及上下文导航。
